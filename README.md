# CLaude-Skill

Skills pour Claude Code et claude.ai.

| Skill | Rôle | Déclenchement |
|---|---|---|
| `grill-me` | Met un plan à l'épreuve, une question à la fois. | `/grill-me`, « challenge mon plan » |
| `humanizer` | Retire les tics d'écriture IA d'un texte sans en changer le fond. | Automatique sur tout texte rédigé, ou `/humanizer` |

Chaque skill est dans `.agents/skills/<nom>/SKILL.md`. Le lien `.claude/skills/<nom>` permet à Claude Code de la trouver.
